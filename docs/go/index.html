desk — windows over panes, in WebAssembly

A small desktop shell for the browser, written in Go and compiled to WebAssembly. winbox-go supplies the window manager — drag, resize, minimize, maximize, modals — websh supplies a bash-like shell, and a pane is anything that renders into a DOM element.

Open a window from the applications menu or from the shell itself, stack windows in the taskbar, and run several programs side by side. A web desktop with no server behind it: the whole environment is wasm running in the page.

Source code: github.com/0magnet/desk. More Go and WebAssembly projects: magnetosphere.net/software.
